# Security policy

## Reporting a vulnerability

Please report security problems privately. Open the [Security and quality tab](https://github.com/mertkayacs/xdfdet/security) of this repository and choose **Report a vulnerability**. Please do not open a public issue for a security problem.

Include the affected file or command, the steps to reproduce it and the impact you expect. I read every report and reply in the private advisory.

## Scope

This policy covers the code in this repository: the `xdfdet` package, its command line and the scripts in `scripts/`. Missed detections and wrong verdicts are known limits of the research models, described in the README, and are out of scope here. Please report those as ordinary issues.

## Supported versions

Fixes go to the `main` branch. The repository has no release branches.
